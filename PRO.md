# Adaptive Agent Emotion — Community and Pro

## Community (this repository)

MIT-licensed, useful standalone affect/state engine:

- affect channels and configurable baselines
- bounded state updates
- decay and recovery
- circadian bias
- session fatigue
- cross-coupling
- familiar/unfamiliar voice events
- tone-response events
- JSON persistence
- model-neutral policy vector

## Pro (proprietary)

The private Pro layer is intended for agents that should learn from the outcomes of their decisions:

- expectation vs outcome observation
- repeated-context learning
- adaptive learning rate
- persistent experience history
- decision advisor summaries
- state-conditioned decision policies
- advanced analytics and integration support

The proprietary observer/advisor implementation is deliberately not included in this public repository.
